در سلول سوم یک برنامه شبیه به عملیات های مدیریت انبار پیاده سازی شده است. برای راحتی سنجش یک لیست اولیه در برنامه ایجاد شده است که می توان از آن استفاده کرد. می توان باز زدن نام و تعداد کالا آن را ثبت کرد اگ کالا از قبل موجود باشد می توان آن را اضافه کرد. می توان در بخش sell فروش کالا را ثبت کرد اگر موجودی کالا 0 بشود نام آن نیز از فهرست حذف می شود.

کالاها به صورت دیکشنری ذخیره شده اند.

در بخش report امکان مشاهده ی تمامی کالا ها، مجموع موجودی ها، کمترین و بیشترین موجودی وجود دارد.
